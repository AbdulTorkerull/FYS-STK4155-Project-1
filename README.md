The coding part of the projects can be found inside the folder "Code". All results are obtained inside the notebook file FYS-STK455_project.ipynb.

All relevant figures, both used and unused in the final report can be found inside folder "Figures"

The report itself is found inside folder "Report".

The folder "Others" contains handwritten notes.
